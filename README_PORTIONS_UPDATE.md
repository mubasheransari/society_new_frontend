# Multiple Portions Frontend Update

Updated screens:
- Add / Update House: admin can add multiple portions while adding a house.
- Dashboard invoice search: when a searched house has portions, admin can select the portion and generate a separate invoice.
- Invoice print copies now show the portion name and resident.

Run:

```bash
npm install
npm run dev
```

## Records Page Existing Plot Portions

Records page now has:

- Show/Hide row details
- Portions count in each plot row
- Existing portions table inside each expanded row
- Add Portion form inside existing plot details
- Delete portion action
- Search includes portion name, resident name, and resident number
